# 刺绣打版术语（准备期）

| 术语 | 含义 | 在 EmbroideryForge 中 |
|------|------|------------------------|
| DST | Tajima 机绣针迹文件 | `auto.dst`（pyembroidery 写出） |
| PES | Brother 等家用格式 | 本仓库暂以 DST 为主验收 |
| Tatami | 榻榻米填针：平行行覆盖大色块 | `stitch=tatami` |
| Satin | 缎面/柱状：左右缘折返，适合窄条 | `stitch=satin`（眼睛等） |
| Running | 走针：沿轮廓稀疏点 | `stitch=running`（描边） |
| Underlay | 底衬针：正式填针前加固 | **未实现**；开题可作扩展 |
| Pull compensation | 布料拉扯补偿（外形外扩） | **未实现**；手工 Ink/Stitch 可调 |
| Density / row spacing | 行距越小针越密 | `--quality dense\|standard\|draft` |
| Color change | 换色指令 | DST 中 `color_change`；层序在 plan |
| stitch_plan | 区域→针法参数契约 | `stitch_plan.json` |

商业软件（Wilcom / Hatch）改的典型 3 个参数：针法类型、密度/行距、填针角度；本仓库用 plan 字段对齐同一语义。
