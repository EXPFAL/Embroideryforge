# EmbroideryForge 开荒教程（台式机 → 笔记本 / 线下实践）

面向：开发在台式机完成，**寒假线下实践改用笔记本电脑**。  
目标：笔记本上 30～60 分钟内跑通「克隆 → 环境 → 样例 DST → 评估」，并能接 DeepSeek。

---

## 0. 两台机器怎么分工

| 机器 | 做什么 |
|------|--------|
| 台式机（当前） | 主开发、调参、出基线；已推 GitHub |
| 笔记本（线下） | 演示、改样例、现场复现；以本仓库为准 |

**不要**整盘拷贝台式机的 `.venv`（路径/架构常不兼容）。  
**不要**把 `.env` 提交进 git；笔记本单独建一份密钥文件。

可选：用 U 盘只拷 `samples/` 里额外图片，或直接 `git pull`。

---

## 1. 软件与下载项（笔记本装机表）

磁盘建议预留 **≥5GB**（Git/Python + venv + rembg 模型；若装 Inkscape 再加约 1GB）。

### 1.1 必装（跑通自动主路径）

| 软件 / 资源 | 版本建议 | 下载 / 入口 | 安装注意 |
|-------------|----------|-------------|----------|
| **Git** | 最新稳定版 | https://git-scm.com/download/win | 默认选项即可；用于 `clone` / `pull` |
| **Python** | **3.11 或 3.12**（x64） | https://www.python.org/downloads/windows/ | 勾选 **Add python.exe to PATH**；可用 `py -3 --version` 自检 |
| **本仓库** | `main` | https://github.com/EXPFAL/Embroideryforge | 见第 2 节克隆；或 Download ZIP（不推荐，难更新） |
| **Python 依赖** | 见 `requirements.txt` | 克隆后 `pip install -r requirements.txt` | 含 OpenCV、pyembroidery、Streamlit、**rembg**、onnxruntime 等 |
| **DeepSeek API Key** | 账号自建 | https://platform.deepseek.com/ → API keys | 写入本地 `.env`；**不要**提交 git。文档：https://api-docs.deepseek.com/zh-cn/ |

PowerShell 7（可选但推荐）：https://github.com/PowerShell/PowerShell/releases  
本机若只有 Windows PowerShell 5.1，教程命令一般仍可用。

### 1.2 强烈建议（复杂背景 / 线下少踩坑）

| 项 | 用途 | 下载说明 |
|----|------|----------|
| **rembg 模型（首次联网）** | `--bg auto` / 照片绣抠人 | 第一次跑复杂图时自动下载到用户目录（常见 `%USERPROFILE%\.u2net` 或 `%USERPROFILE%\.rembg`）。**台式机先跑一遍**，再用 U 盘拷整个缓存目录到笔记本同路径，避免现场慢网 |
| **MediaPipe `.task`（照片绣）** | 脸/手/姿态 | 见 `models/README.md`；可预下载到仓库 `models\`（已 gitignore `*.task`）。**U 盘拷 `models\*.task` 到笔记本同路径** |
| **U 盘备份包** | 离线救急 | 见下方 **§1.7 U 盘清单** |

### 1.3 可选：手工打版对照（Inkscape + Ink/Stitch）

自动 `stitch-auto` **不依赖**下列软件；仅当需要「工业旁路 / 老师要看 Ink/Stitch 文件」时安装。

| 软件 | 版本建议 | 下载 / 文档 | 注意 |
|------|----------|-------------|------|
| **Inkscape** | **1.4.x 官方 x64** | https://inkscape.org/release/ | **不要**用微软 Store 残缺包；台式机曾用 `D:\TOOL\Inkscape`。安装选系统级或便携目录均可 |
| **Ink/Stitch** | 与 Inkscape 匹配的 Windows 安装包 | 安装说明：https://inkstitch.org/docs/install-windows/ ；发布页：https://github.com/inkstitch/inkstitch/releases | 装到 Inkscape 的 `extensions`；装完在 Inkscape 菜单应出现 **Ink/Stitch**。导出 DST：`File → Save As`（扩展名 `.dst`），不要只靠 Visualize |
| **7-Zip**（可选） | 最新 | https://www.7-zip.org/ | 解压 Inkscape 便携包 / 安装包时用 |

Ink/Stitch 最小手走一遍：导入样例图 → 位图描摹 → 解组清理 → Params（Tatami/Running）→ Save As `.dst`。  
对照样例思路见仓库内手工产物说明（若本地有历史 `exports`，以 git 中文档为准）。

### 1.4 了解即可（不必装上笔记本）

| 名称 | 用途 | 链接 |
|------|------|------|
| Wilcom / Hatch | 商业打版流程调研 | 自行检索官网；只读笔记 |
| pyembroidery（上游） | DST 读写库（已随 pip 安装） | https://github.com/EmbroidePy/pyembroidery |
| StarVector / MSEmb 等 | 课题扩展阅读 | 见 `docs/research/资源收集清单.md` |

### 1.5 一键自检命令（装完 Git + Python 后）

```powershell
git --version
py -3 --version
# 克隆并建 venv 之后：
.\.venv\Scripts\python.exe -c "import cv2, pyembroidery, rembg; print('deps ok')"
```

### 1.6 下载优先级（赶时间）

1. Git + Python → 克隆 → `pip install -r requirements.txt` → `.env`  
2. 白底 `golden-chibi` 跑通（可不装 Inkscape）  
3. 预热 rembg（复杂背景）  
4. 预热 MediaPipe（跑一张 `stitch-photo`，或按 `models/README.md` curl）  
5. 有余力再装 Inkscape + Ink/Stitch  

### 1.7 U 盘迁移清单（台式机 → 笔记本）

| 拷贝项 | 源（台式机） | 目标（笔记本） |
|--------|--------------|----------------|
| 代码 | `git pull` 优先；或 zip / `git bundle` | 短路径仓库根 |
| 密钥 | 根目录 `.env`（**仅私人盘**） | 同路径 `.env` |
| rembg 缓存 | `%USERPROFILE%\.u2net` 或 `.rembg` | 同用户目录同名文件夹 |
| MediaPipe | `models\*.task` | 仓库 `models\` |
| 冻结预览（可选） | `exports\accept_flat_v3\`、`exports\photo_stitch_exp\figure_*_v63d\` 中 PNG/DST | 同相对路径（`exports/` 默认不进 git） |
| 样例 | `samples\`（仓库已含主样例） | `git pull` 即可 |

**不要**拷贝 `.venv`。冻结目录说明：[`docs/BASELINE.md`](BASELINE.md)。

## 2. 克隆仓库

在资源管理器里选一个短路径，例如 `D:\CODE` 或 `C:\Work`（避免过长中文路径）。

```powershell
cd D:\CODE
git clone https://github.com/EXPFAL/Embroideryforge.git
cd Embroideryforge
```

若已克隆，线下前先更新：

```powershell
cd D:\CODE\Embroideryforge
git pull
```

---

## 3. 创建虚拟环境并装依赖

```powershell
cd D:\CODE\Embroideryforge
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
pip install -r requirements.txt
```

若 `Activate.ps1` 被策略拦截：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### rembg 说明（复杂背景）

`requirements.txt` 含 `rembg` / `onnxruntime`。  
**第一次**对复杂背景图跑 `--bg auto` 时，会下载 ONNX 模型（需联网，可能数分钟）。  
模型缓存在用户目录 `%USERPROFILE%\.u2net` 或 `%USERPROFILE%\.rembg` 一类路径；台式机下好后可用 U 盘拷到笔记本同路径，减少现场下载。

白底插画样例会跳过去背景，不强制 rembg。

## 4. 配置 DeepSeek（LLM 针法计划）

```powershell
copy .env.example .env
notepad .env
```

填写（勿提交、勿发聊天）：

```text
DEEPSEEK_API_KEY=sk-你的密钥
DEEPSEEK_MODEL=deepseek-flash
```

无 Key 时仍可用规则计划（去掉 `--llm`）。

## 5. 自检：测试与黄金样例

```powershell
.\.venv\Scripts\Activate.ps1
python -m pytest -q
```

期望：全部 passed。

白底 chibi 全链路（默认 dense + auto 去背景）：

```powershell
python -m embroideryforge stitch-auto samples\golden-chibi.jpg --out exports\laptop_smoke --llm --k 12 --quality dense --bg auto
python -m embroideryforge evaluate exports\laptop_smoke --image samples\golden-chibi.jpg
```

看这些文件：

- `exports\laptop_smoke\auto.png` — 主预览（色对齐）
- `exports\laptop_smoke\stitch_plan.json` — 规则/LLM 计划
- `exports\laptop_smoke\evaluate_report.json` — 含 `rubric` 五维分

复杂背景（需 rembg 模型）：

```powershell
python -m embroideryforge stitch-auto samples\test_chibi_complex_bg.jpg --out exports\laptop_complex --llm --quality dense --bg auto
```

照片绣冒烟（需 rembg；MediaPipe 可选，失败会 bust 回退）：

```powershell
python -m embroideryforge stitch-photo samples\test_figure_cowboy.jpg --out exports\laptop_photo_cowboy --mode hybrid --density-unified --bg keep --colors 12 --resolution high
```

看 `compare_preview.png` / `auto_stitch_thick.png`；人评口径见 `docs\路线-照片绣PhotoStitch.md` 附录 A（**不**要求 `rubric_pass_95`）。

## 6. 常用命令速查

| 目的 | 命令 |
|------|------|
| 只要分区 | `python -m embroideryforge segment samples\golden-chibi.jpg --out exports\seg1` |
| 规则写 plan | `python -m embroideryforge plan exports\seg1\layers.json --quality dense` |
| LLM 写 plan | `python -m embroideryforge plan exports\seg1\layers.json --llm --quality dense` |
| 端到端 DST | `python -m embroideryforge stitch-auto <图> --out exports\run --llm` |
| 评估 | `python -m embroideryforge evaluate exports\run --image <图>` |
| 照片绣场景 | `python -m embroideryforge stitch-photo <图> --out exports\ps --mode hybrid --density-unified --bg keep --colors 12 --resolution high` |
| GUI（可选） | `python -m streamlit run app\streamlit_app.py` |

## 8. 现场常见问题

| 现象 | 处理 |
|------|------|
| `DEEPSEEK_API_KEY not set` / plan 变 `rules_fallback` | 检查 `.env` 是否在仓库根目录、变量名是否正确 |
| `pytest` 找不到包 | 是否激活了 `.venv` |
| rembg 很慢/失败 | 先白底样例演示；或提前下好模型；可用 `--bg off`（复杂背景质量会差） |
| PowerShell 无法激活 venv | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| 路径含空格 | 给路径加引号：`cd "D:\My Projects\Embroideryforge"` |

## 10. 线下演示建议顺序（约 10 分钟）

1. 打开本教程 + `docs\课题一设计说明-chibi基线.md`  
2. 跑白底 `stitch-auto --llm`，展示 `layers_compare.png` 与 `auto.png`  
3. 打开 `stitch_plan.json`，说明 LLM 只改计划、工具执行、evaluate 验收  
4. （有余力）复杂背景一张，强调 `--bg auto`  
5. 对照课题评估五维：`evaluate_report.json` 里的 `rubric`
