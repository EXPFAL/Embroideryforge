# EmbroideryForge 开荒教程（台式机 → 笔记本 / 线下实践）

面向：开发在台式机完成，**寒假线下实践改用笔记本电脑**。  
目标：笔记本上 30～60 分钟内跑通「克隆 → 环境 → 样例 DST → 评估」，并能接 DeepSeek。

---

## 0. 两台机器怎么分工

| 机器 | 做什么 |
|------|--------|
| 台式机（当前） | 主开发、调参、出基线；已推 GitHub |
| 笔记本（线下） | 演示、改样例、现场复现；以本仓库为准 |

**不要**整盘拷贝台式机的 `.venv`（路径/架构常不兼容）。  
**不要**把 `.env` 提交进 git；笔记本单独建一份密钥文件。

可选：用 U 盘只拷 `samples/` 里额外图片，或直接 `git pull`。

---

## 1. 笔记本准备清单

- Windows 10/11，能上网（首次装依赖、可选拉 rembg 模型）
- [Git](https://git-scm.com/download/win)
- [Python 3.11+](https://www.python.org/downloads/)（安装勾选 *Add python.exe to PATH*）
- GitHub 账号能读本仓库：https://github.com/EXPFAL/Embroideryforge
- DeepSeek API Key（线下要用 `--llm` 时）：https://platform.deepseek.com/
- （可选对照）Inkscape 1.4.x + Ink/Stitch——仅手工打版对照，**自动主路径不依赖**

磁盘：建议预留 **≥3GB**（venv + rembg 模型）。

---

## 2. 克隆仓库

在资源管理器里选一个短路径，例如 `D:\CODE` 或 `C:\Work`（避免过长中文路径）。

```powershell
cd D:\CODE
git clone https://github.com/EXPFAL/Embroideryforge.git
cd Embroideryforge
```

若已克隆，线下前先更新：

```powershell
cd D:\CODE\Embroideryforge
git pull
```

---

## 3. 创建虚拟环境并装依赖

```powershell
cd D:\CODE\Embroideryforge
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
pip install -r requirements.txt
```

若 `Activate.ps1` 被策略拦截：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### rembg 说明（复杂背景）

`requirements.txt` 含 `rembg` / `onnxruntime`。  
**第一次**对复杂背景图跑 `--bg auto` 时，会下载 ONNX 模型（需联网，可能数分钟）。  
模型缓存在用户目录 `%USERPROFILE%\.u2net` 或 `%USERPROFILE%\.rembg` 一类路径；台式机下好后可用 U 盘拷到笔记本同路径，减少现场下载。

白底插画样例会跳过去背景，不强制 rembg。

---

## 4. 配置 DeepSeek（LLM 针法计划）

```powershell
copy .env.example .env
notepad .env
```

填写（勿提交、勿发聊天）：

```text
DEEPSEEK_API_KEY=sk-你的密钥
DEEPSEEK_MODEL=deepseek-flash
```

无 Key 时仍可用规则计划（去掉 `--llm`）。

---

## 5. 自检：测试与黄金样例

```powershell
.\.venv\Scripts\Activate.ps1
python -m pytest -q
```

期望：全部 passed。

白底 chibi 全链路（默认 dense + auto 去背景）：

```powershell
python -m embroideryforge stitch-auto samples\golden-chibi.jpg --out exports\laptop_smoke --llm --k 12 --quality dense --bg auto
python -m embroideryforge evaluate exports\laptop_smoke --image samples\golden-chibi.jpg
```

看这些文件：

- `exports\laptop_smoke\auto.png` — 主预览（色对齐）
- `exports\laptop_smoke\stitch_plan.json` — 规则/LLM 计划
- `exports\laptop_smoke\evaluate_report.json` — 含 `rubric` 五维分

复杂背景（需 rembg 模型）：

```powershell
python -m embroideryforge stitch-auto samples\test_chibi_complex_bg.jpg --out exports\laptop_complex --llm --quality dense --bg auto
```

## 6. 常用命令速查

| 目的 | 命令 |
|------|------|
| 只要分区 | `python -m embroideryforge segment samples\golden-chibi.jpg --out exports\seg1` |
| 规则写 plan | `python -m embroideryforge plan exports\seg1\layers.json --quality dense` |
| LLM 写 plan | `python -m embroideryforge plan exports\seg1\layers.json --llm --quality dense` |
| 端到端 DST | `python -m embroideryforge stitch-auto <图> --out exports\run --llm` |
| 评估 | `python -m embroideryforge evaluate exports\run --image <图>` |
| GUI（可选） | `python -m streamlit run app\streamlit_app.py` |

课题说明与基线：`docs\课题一设计说明-chibi基线.md`、`docs\BASELINE.md`、`docs\PRODUCT.md`。

## 8. 现场常见问题

| 现象 | 处理 |
|------|------|
| `DEEPSEEK_API_KEY not set` / plan 变 `rules_fallback` | 检查 `.env` 是否在仓库根目录、变量名是否正确 |
| `pytest` 找不到包 | 是否激活了 `.venv` |
| rembg 很慢/失败 | 先白底样例演示；或提前下好模型；可用 `--bg off`（复杂背景质量会差） |
| PowerShell 无法激活 venv | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| 路径含空格 | 给路径加引号：`cd "D:\My Projects\Embroideryforge"` |

## 10. 线下演示建议顺序（约 10 分钟）

1. 打开本教程 + `docs\课题一设计说明-chibi基线.md`  
2. 跑白底 `stitch-auto --llm`，展示 `layers_compare.png` 与 `auto.png`  
3. 打开 `stitch_plan.json`，说明 LLM 只改计划、工具执行、evaluate 验收  
4. （有余力）复杂背景一张，强调 `--bg auto`  
5. 对照课题评估五维：`evaluate_report.json` 里的 `rubric`
